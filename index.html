관리자 모드

비밀번호를 입력하면 어느 기기에서나 내 디자인을 모두 볼 수 있어요.

아직 클라우드 주소가 설정되지 않았어요. js/config.js에 주소를 넣으면 모든 기기에서 비밀번호만으로 접속됩니다. 지금은 이 기기에 저장된 디자인만 보여요.

dashboard내 디자인관리자

cloud_off 클라우드가 연결되지 않았어요
처음 연결하는 방법 (1번만 하면 모든 기기에서 비밀번호만으로 접속)
  1. script.google.com에서 새 프로젝트를 만들고, 저장소의 gas/Code.gs 내용을 붙여넣어요.
  2. [프로젝트 설정 ⚙️] → [스크립트 속성]에 SECRET = 내가 정한 비밀번호를 추가해요.
  3. [배포] → [새 배포] → 유형 웹 앱 → 액세스 모든 사용자로 배포해요.
  4. 발급된 …/exec 주소를 저장소의 js/config.js 파일 GAS_URL에 붙여넣고 저장(커밋)해요.
  5. 끝! 이제 어느 기기에서든 관리자 모드에 들어가 비밀번호만 입력하면 모든 디자인이 보여요.
  6. 코드를 고쳤다면 [배포 관리 → 수정 → 새 버전]으로 다시 배포해야 반영돼요.

🔒 주소(URL)는 공개돼도 안전해요 — 실제 잠금은 비밀번호(SECRET)이고 서버에서만 검증돼요. 비밀번호는 코드/저장소에 넣지 말고 앱에서만 입력하세요(이 브라우저에만 기억).
