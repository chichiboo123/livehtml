# Live HTML

> HTML로 만든 **카드뉴스 · 인포그래픽 · PPT · 포스터**를 코드를 몰라도
> 캔바(Canva)처럼 화면에서 바로 고치고, 수정된 HTML과 PNG로 받아볼 수 있는 웹앱

코드 입력창에 HTML을 넣으면 실시간으로 결과가 보이고, **보이는 화면에서 직접
글자를 고치거나 요소를 끌어 옮기면 그대로 HTML 코드에 반영**됩니다.
완성된 결과물은 HTML 코드 복사·다운로드는 물론, 페이지별 PNG 이미지로도 저장할 수 있습니다.

빌드 도구·서버·프레임워크 없이 **순수 HTML / CSS / JavaScript** 만으로 동작합니다.

---

## ✨ 주요 기능

### 1. 불러오기
| 방법 | 설명 |
|---|---|
| 파일 업로드 | `.html` / `.htm` 파일 선택 |
| 클립보드 붙여넣기 | 버튼 한 번으로 복사해 둔 코드 불러오기 |
| 드래그 & 드롭 | HTML 파일을 화면 아무 곳에나 끌어다 놓기 |
| 직접 입력 | 코드창에 바로 타이핑 (실시간 반영) |
| 예시로 둘러보기 | 사용법이 적힌 3페이지 샘플 카드뉴스 제공 |

### 2. 실시간 미리보기
- 코드를 고치는 즉시 미리보기에 반영
- **자동 맞춤 / 50 ~ 125% 배율** — 고정폭(예: 600px) 카드뉴스도 화면에 맞게 표시
- **편집 모드 / 보기 모드** 전환

### 3. 화면에서 바로 편집 (편집 모드)
| 동작 | 결과 |
|---|---|
| 한 번 클릭 | 요소 선택 → 편집 도구 막대 표시 |
| 두 번 클릭 | 텍스트 내용 수정 |
| 드래그 | 요소 위치 이동 |
| 방향키 / Shift+방향키 | 1px / 10px 미세 이동 |
| Delete | 선택한 요소 삭제 |
| Esc | 편집 종료 · 선택 해제 |

**편집 도구 막대에서 할 수 있는 것**
- **글꼴 변경** — Pretendard · Pretendard GOV + Google Fonts **한글 글꼴 전체(37종)** + 영문 글꼴 16종, 한글/영문 검색 지원.
  적용한 글꼴의 `<link>`가 문서에 함께 저장되어 **다운로드한 HTML에서도 글꼴이 유지**됩니다.
- 글자 크기(직접 입력 또는 ±버튼) · 굵게 · 기울임 · 글자 색 · 정렬(왼쪽/가운데/오른쪽)
- 이미지 교체(파일 선택 → 자동 내장) · 복제 · 위치 초기화 · 상위 요소 선택 · 삭제

**가운데 정렬 가이드선** 🧲
요소를 드래그하다가 부모 컨테이너의 가로/세로 가운데에 가까워지면
분홍색 가이드선이 나타나며 **자석처럼 착 붙습니다(스냅)**. 가로·세로 모두 지원합니다.

화면에서 수정한 모든 내용은 **HTML 코드에 자동 반영**됩니다.

### 4. 안전장치
- **실행 취소 / 다시 실행** — Ctrl(⌘)+Z / Ctrl(⌘)+Y, 최근 100단계
- **자동 저장** — 작업 내용이 브라우저(localStorage)에 자동 저장되어, 창을 닫았다 다시 열어도 이어서 작업
- 편집 중 링크 클릭으로 작업물이 사라지지 않도록 페이지 이동 차단

### 5. 결과물 공유 및 다운로드
- **HTML 복사** — 수정된 코드를 클립보드로
- **HTML 다운로드** — `.html` 파일 저장 (Ctrl+S 단축키 지원)
- **PNG 다운로드** — `.page` `.slide` `section` 등으로 **페이지를 자동 감지**해
  원하는 페이지만 골라 2배 해상도 PNG로 저장
- **공유** — 모바일에서 Web Share API로 HTML 파일 바로 공유

### 6. 반응형 (PC · 모바일)
- PC: 코드 / 미리보기 분할 화면, 경계선을 끌어 비율 조절
- 모바일: 하단 탭바로 코드 ↔ 미리보기 전환, 터치로 선택·드래그·편집

- 아이콘: **Google Material Symbols**
- 기본 글꼴: **Pretendard**

## 📁 프로젝트 구조

```
livehtml/
├── index.html        # 앱 레이아웃 (헤더/코드창/미리보기/모달/푸터)
├── favicon.svg       # 파비콘
├── css/
│   └── style.css     # KRDS 기반 디자인 토큰 + 전체 스타일
└── js/
    └── app.js        # 렌더링·인라인 편집·동기화·내보내기 로직
```

## 🚀 실행 방법

정적 파일이므로 그대로 열면 됩니다.

```bash
# 방법 1: index.html을 브라우저로 직접 열기
# 방법 2: 아무 정적 서버 (예시)
npx http-server .
python3 -m http.server 8000
```

GitHub Pages, Netlify, Vercel 등 어떤 정적 호스팅에도 바로 배포할 수 있습니다.

> 글꼴(Google Fonts, Pretendard CDN)과 PNG 변환(html2canvas CDN)은
> 인터넷 연결이 필요합니다.

## ⚙️ 동작 원리 (간단히)

1. 입력한 HTML을 같은 출처(srcdoc) `iframe`에 렌더링합니다.
2. 편집 모드에서 iframe 문서에 직접 이벤트를 연결해 선택·드래그·텍스트 수정을 처리합니다.
   위치 이동은 원본을 최대한 해치지 않도록 인라인 `transform: translate()`로 기록합니다.
3. 수정이 일어나면 편집용 표시(하이라이트, 가이드선, `contenteditable` 등)를 모두 걷어낸
   **깨끗한 HTML만 직렬화**해서 코드창에 반영합니다.
4. PNG 내보내기는 iframe 안에 html2canvas를 주입해 페이지 요소를 캔버스로 그려 저장합니다.
