# Live HTML

> HTML로 만든 **카드뉴스 · 인포그래픽 · PPT · 포스터**를 코드를 몰라도
> 캔바(Canva)처럼 화면에서 바로 고치고, 수정된 HTML과 PNG로 받아볼 수 있는 웹앱

코드 입력창에 HTML을 넣으면 실시간으로 결과가 보이고, **보이는 화면에서 직접
글자를 고치거나 요소를 끌어 옮기면 그대로 HTML 코드에 반영**됩니다.
완성된 결과물은 HTML 코드 복사·다운로드는 물론, 페이지별 PNG 이미지로도 저장할 수 있습니다.

빌드 도구·서버·프레임워크 없이 **순수 HTML / CSS / JavaScript** 만으로 동작합니다.

## ✨ 주요 기능

### 1. 불러오기
| 방법 | 설명 |
|---|---|
| 파일 업로드 | `.html` / `.htm` 파일 선택 |
| 클립보드 붙여넣기 | 버튼 한 번으로 복사해 둔 코드 불러오기 |
| 드래그 & 드롭 | HTML 파일을 화면 아무 곳에나 끌어다 놓기 |
| 직접 입력 | 코드창에 바로 타이핑 (실시간 반영) |
| 템플릿으로 시작 | 사용법 예시 · 카드뉴스(1080×1080) · 행사 포스터(A4) · 프레젠테이션(1280×720) |

### 2. 실시간 미리보기
- 코드를 고치는 즉시 미리보기에 반영
- **자동 맞춤 / 50 ~ 125% 배율** — 고정폭(예: 600px) 카드뉴스도 화면에 맞게 표시
- **편집 모드 / 보기 모드** 전환
- **페이지 구분 표시** — 여러 페이지로 된 문서는 페이지마다 점선 테두리와
  `페이지 N` 라벨이 붙어 어디까지가 한 페이지인지 한눈에 보여요
- 코드창은 **줄 번호**가 표시되는 일반적인 코드 편집기 형태

### 3. 화면에서 바로 편집 (편집 모드)
| 동작 | 결과 |
|---|---|
| 한 번 클릭 | 요소 선택 → 편집 도구 막대 + 모서리 크기 조절 핸들 표시 |
| 두 번 클릭 | 텍스트 내용 수정 |
| 드래그 | 요소 위치 이동 |
| 모서리 핸들 드래그 | 크기 조절 (이미지는 비율 유지, 텍스트는 글자 크기 조절) |
| 위쪽 파란 핸들 드래그 | 회전 (45° 근처에서 자석처럼 스냅) |
| 방향키 / Shift+방향키 | 1px / 10px 미세 이동 |
| Delete | 선택한 요소 삭제 |
| Esc | 편집 종료 · 선택 해제 |

**요소 추가 (오른쪽 아래 + 버튼)** — 캔바처럼 원하는 요소를 페이지에 추가해요
- 텍스트: 제목 · 부제목 · 본문 · 배경 있는 텍스트 상자
- 도형: 사각형 · 둥근 사각형 · 원 · 삼각형 · 선 (채우기 색 변경 가능)
- 이모지: 표정 / 사람 / 하트 / 자연 / 음식 / 활동 / 사물 / 기호 **8개 카테고리 500여 종**
- 이미지: 내 기기의 사진 업로드 (HTML 안에 내장되어 함께 저장, 크기 조절 가능)
- 추가된 요소는 보이는 페이지의 가운데에 들어가며, 드래그·크기 조절·삭제 모두 가능해요

**페이지 배경색 변경** — `페이지 N` 라벨을 누르면 페이지가 통째로 선택되고,
도구 막대의 채우기(🪣) 버튼으로 배경색을 바꿀 수 있어요. 도형·텍스트 상자에도 똑같이 적용돼요.

**편집 도구 막대에서 할 수 있는 것**
- **글꼴 변경** — Pretendard · Pretendard GOV + Google Fonts **한글 글꼴 전체(37종)** + 영문 글꼴 16종, 한글/영문 검색 지원.
  적용한 글꼴의 `<link>`가 문서에 함께 저장되어 **다운로드한 HTML에서도 글꼴이 유지**됩니다.
- 글자 크기(직접 입력 또는 ±버튼) · 굵게 · 기울임 · 글자 색 · 배경(채우기) 색 · 정렬(왼쪽/가운데/오른쪽)
- 배경색 패널에는 **최근 사용한 색(자동 저장)** 과 기본 팔레트가 있어, 다음 페이지에도
  같은 색을 한 번에 적용할 수 있어요 (페이지를 바꿔 선택해도 패널이 열린 채 유지)
- **글자 효과(✨)** — 그림자 · 외곽선 · 네온 · 입체 프리셋과 효과 색상 선택 (PNG 내보내기에도 그대로 반영)
- 이미지 교체(파일 선택 → 자동 내장) · 복제 · 위치·회전 초기화 · 상위 요소 선택 · 삭제

**가운데 정렬 가이드선** 🧲
요소를 드래그하다가 부모 컨테이너의 가로/세로 가운데에 가까워지면
분홍색 가이드선이 나타나며 **자석처럼 착 붙습니다(스냅)**. 가로·세로 모두 지원합니다.

화면에서 수정한 모든 내용은 **HTML 코드에 자동 반영**됩니다.

### 4. 안전장치
- **실행 취소 / 다시 실행** — Ctrl(⌘)+Z / Ctrl(⌘)+Y, 최근 100단계
- **자동 저장** — 작업 내용이 브라우저(localStorage)에 자동 저장되어, 창을 닫았다 다시 열어도 이어서 작업
- 편집 중 링크 클릭으로 작업물이 사라지지 않도록 페이지 이동 차단

### 5. 결과물 공유 및 다운로드 — [저장 · 공유] 버튼 하나로
- **HTML 파일로 저장** — `.html` 파일 저장 (Ctrl+S 단축키 지원)
- **HTML 코드 복사** — 수정된 코드를 클립보드로 (코드창의 '복사' 버튼으로도 가능)
- **PNG 다운로드** — `.page` `.slide` `section` 등으로 **페이지를 자동 감지**한 뒤
  캔바·미리캔버스처럼 원하는 방식으로 저장
  - **페이지별로 저장**: 원하는 페이지만 선택, 여러 장이면 ZIP으로 묶어서 한 번에
  - **한 장으로 저장**: 선택한 페이지를 세로로 이어붙인 긴 이미지 한 장으로
  - **이미지 크기**: 기본은 긴 변 1920px(정사각형이면 1920×1920)로 키워서 저장,
    고화질(3840px)·원본 크기도 선택 가능
- **공유** — 모바일에서 Web Share API로 HTML 파일 바로 공유

### 6. 반응형 (PC · 모바일)
- PC: 코드 / 미리보기 분할 화면, 경계선을 끌어 비율 조절
- 모바일: 하단 탭바로 코드 ↔ 미리보기 전환, 터치로 선택·드래그·편집
- 화면 회전·창 크기 변경을 감지해 미리보기 배율을 자동으로 다시 맞춤
- 터치 기기에서는 버튼·이모지가 자동으로 더 커져 어린이·어르신도 누르기 쉬워요

### 7. 처음 사용자 안내
- 첫 방문 시 4단계 사용 방법 안내가 자동으로 열리고, 언제든 헤더의 ? 버튼으로 다시 볼 수 있어요

### 8. 내 디자인 (숨김 관리자 모드)
캔바의 '프로젝트'처럼 만든 HTML을 모아 두고 관리하는 개인 대시보드예요.

- **들어가기**: 헤더의 로고를 **5번 연속 클릭**하거나, 주소 끝에 `#admin`을 붙여 접속
- 한 번 열면 헤더에 **[저장] [내 디자인]** 버튼이 계속 보여서 작업창 ↔ 대시보드를
  한 번의 클릭으로 오갈 수 있어요 (대시보드의 🔒 버튼으로 다시 숨김)
- 대시보드에서 **[새 디자인]** (또는 첫 칸의 + 카드)을 누르면 템플릿/빈 캔버스를 골라
  바로 작업을 시작하고, **[편집으로]** 버튼으로 즉시 작업창으로 돌아와요
- 디자인 카드를 누르면 **편집 중** 상태로 연결되어, 헤더 [저장](또는 Ctrl+S)이
  묻지 않고 그 디자인에 바로 덮어써요. 새 파일/템플릿을 불러오면 연결이 풀려요
- **카드형 / 리스트형** 보기 전환, 편집 중인 디자인은 파란 테두리 + '편집 중' 배지
- 카드에서 바로: 열기 · 복제 · 이름 바꾸기 · **HTML 다운로드** · 삭제
- 기본 저장 위치는 **이 브라우저(localStorage)** — 서버 없이 바로 동작해요

**클라우드 저장 (선택, Google Apps Script)**
여러 기기에서 쓰고 싶다면 내 Google Drive로 백업할 수 있어요.
주소는 비밀번호(스크립트 속성의 `SECRET`)로 보호되므로, 주소가 노출돼도 안전합니다.

1. [script.google.com](https://script.google.com)에서 새 프로젝트를 만들고 [`gas/Code.gs`](gas/Code.gs) 내용을 붙여넣기
2. **[프로젝트 설정 ⚙️] → [스크립트 속성]** 에 `SECRET` = 내가 정한 비밀번호를 추가
3. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: **모든 사용자**)로 배포
4. 발급된 `…/exec` 주소와 비밀번호를 관리자 모드 [클라우드] 칸에 **한 번만** 입력하면
   이 브라우저에 저장되어 다시 입력할 필요가 없어요
   (비밀번호는 코드/저장소에 넣지 않고 브라우저에만 보관 → 외부 노출 방지)
5. **자동으로 클라우드에 저장**을 켜면 디자인을 저장·수정할 때마다 자동 백업되고,
   상태줄에 마지막 백업 시각이 표시돼요. 다른 기기에서는 **[클라우드에서 불러오기]** 한 번이면 끝
6. 디자인 본문은 내 Drive의 `livehtml-designs.json` 파일(항상 같은 파일 ID로 고정 →
   복원이 안정적)에, 보기용 목록은 `Live HTML 디자인 목록` 스프레드시트에 자동 기록돼요
7. **코드를 수정한 뒤에는** [배포 → 배포 관리 → 수정 → 버전: 새 버전 → 배포]를
   해야 같은 URL에 반영돼요 (저장만 하면 옛 코드가 계속 실행됨)

> 🔒 **왜 주소를 완전히 숨길 수 없나요?** 이 앱은 서버 없는 정적 사이트라,
> 브라우저가 Apps Script 주소를 알아야만 호출할 수 있어요(네트워크 탭에 보임).
> 그래서 주소 자체를 숨기는 대신, **진짜 비밀인 비밀번호를 서버(스크립트 속성)에 두고**
> 검증하는 방식으로 안전하게 만들었습니다.

## 📁 프로젝트 구조

```
livehtml/
├── index.html        # 앱 레이아웃 (헤더/코드창/미리보기/모달/푸터)
├── favicon.svg       # 파비콘
├── css/
│   └── style.css     # KRDS 기반 디자인 토큰 + 전체 스타일
└── js/
    └── app.js        # 렌더링·인라인 편집·동기화·내보내기 로직
```

## 🚀 실행 방법

정적 파일이므로 그대로 열면 됩니다.

```bash
# 방법 1: index.html을 브라우저로 직접 열기
# 방법 2: 아무 정적 서버 (예시)
npx http-server .
python3 -m http.server 8000
```

GitHub Pages, Netlify, Vercel 등 어떤 정적 호스팅에도 바로 배포할 수 있습니다.

> 글꼴(Google Fonts, Pretendard CDN)과 PNG 변환(html2canvas CDN)은
> 인터넷 연결이 필요합니다.

## ⚙️ 동작 원리 (간단히)

1. 입력한 HTML을 같은 출처(srcdoc) `iframe`에 렌더링합니다.
2. 편집 모드에서 iframe 문서에 직접 이벤트를 연결해 선택·드래그·텍스트 수정을 처리합니다.
   위치 이동은 원본을 최대한 해치지 않도록 인라인 `transform: translate()`로 기록합니다.
3. 수정이 일어나면 편집용 표시(하이라이트, 가이드선, `contenteditable` 등)를 모두 걷어낸
   **깨끗한 HTML만 직렬화**해서 코드창에 반영합니다.
4. PNG 내보내기는 iframe 안에 html2canvas를 주입해 페이지 요소를 캔버스로 그려 저장합니다.
