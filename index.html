cloud_off 클라우드가 연결되지 않았어요
처음 연결하는 방법 (1번만 하면 돼요)
  1. script.google.com에서 새 프로젝트를 만들고, 저장소의 gas/Code.gs 내용을 붙여넣어요.
  2. [배포] → [새 배포] → 유형 웹 앱 → 액세스 모든 사용자로 배포해요.
  3. 발급된 …/exec 주소를 위 칸에 붙여넣으면 끝! (한 번만 하면 계속 기억해요)
  4. 코드를 고쳤다면 [배포 관리 → 수정 → 새 버전]으로 다시 배포해야 반영돼요.

⚠️ 이 주소를 아는 사람은 백업을 읽고 쓸 수 있으니 비밀로 관리하세요.
